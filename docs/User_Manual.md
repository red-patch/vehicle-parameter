# 智行参数管理系统 - 用户使用手册

## 1. 产品简介

智行参数管理系统 (Vehicle Parameter Manager) 是一款专为车辆工程、投标及数据管理场景设计的辅助工具。致力于解决 Excel 参数表版本迭代频繁、投标填报繁琐等痛点，提供秒级版本差异比对、智能模糊匹配填报及公告数据查询等功能，显著提升工作效率与数据准确性。

## 2. 核心功能

### 2.1 Excel 版本差异比对 (Version Diff)

此功能用于快速识别两个 Excel 版本之间的参数变更（新增、删除、数值修改）。

**使用步骤：**

1.  **上传基准版**：在首页“版本比对”页签左侧，点击或拖拽上传旧版 Excel 文件（基准文件）。
2.  **上传新版本**：在右侧区域上传新版 Excel 文件。
3.  **查看差异结果**：
    - 系统会自动计算并显示差异概览（新增、移除、变更数量）。
    - 下方列表详细展示具体的字段差异，支持：
      - **变更 (Modified)**：黄色高亮，显示新旧数值对比。
      - **新增 (Added)**：绿色高亮，显示新版本独有的字段。
      - **移除 (Removed)**：红色高亮，显示已被删除的字段。
    - **筛选查看**：可通过顶部的下拉菜单按“工作表 (Sheet)” 筛选特定分页的数据。

### 2.2 智能投标填报 (Smart Bidding Filler)

利用模糊匹配算法，自动从参数库中提取数据填充到招标需求表中，减少人工查找时间。

**前提条件：**

- 必须先在“版本比对”页面上传**基准版 Excel**，系统将以该文件作为**标准参数库 (Library)**。

**使用步骤：**

1.  **进入功能页**：点击顶部导航栏的“智能检索与填充”。
2.  **选择车型 (可选)**：如果参数库包含多个车型，可在下拉框中指定匹配范围（如不选则默认全库匹配）。
3.  **输入需求**：
    - **方式一：文件上传**：直接上传招标方提供的 Excel 需求表。
    - **方式二：文本输入**：切换到“文本输入”页签，手动粘贴参数名（支持逗号或换行分隔）。
4.  **审核与修正**：
    - 系统会自动列出匹配结果，根据置信度标记颜色（绿色为高置信度，黄色/红色需重点复核）。
    - **人工修正**：如果匹配不准确，点击下拉框手动搜索并选择正确的参数。
    - **应用修改**：确认无误后点击“确认并应用”，所有手动修正将被锁定。
5.  **导出结果**：点击右上角“导出结果”按钮，下载填报完成的 Excel 文件。

### 2.3 公告号查询 (Announcement Query)

支持查询工信部车辆公告详细技术参数。

**使用步骤：**

1.  点击顶部导航栏的“公告号查询”。
2.  在搜索框输入完整的公告型号（例如：`DNC5037XXYBEVP1`）。
3.  点击查询，系统将从 MIIT 官网获取车辆详情。
4.  支持将查询结果导出为 CSV 文件。

## 3. 常见问题 (FAQ)

**Q: 支持哪些文件格式？**
A: 支持 `.xlsx` 和 `.xls` 格式的 Excel 文件，导出功能默认使用 `.xlsx` 或 `.csv`。

**Q: 为什么智能填报无法使用？**
A: 请检查是否已在“版本比对”页面上传了基准版文件。智能填报依赖基准文件作为数据源。

**Q: 如何处理多个 Sheet 页的数据？**
A: 系统支持多 Sheet 页解析。在预览和比对时，可以通过下拉菜单选择“全部工作表”或指定某个 Sheet 进行查看。

**Q: 匹配准确率不高怎么办？**
A: 智能匹配基于模糊算法，对于名称差异过大的字段（如“全长”与“车身长度”），首次可能匹配失败。建议在结果页手动修正，人工确认后的准确性为 100%。
