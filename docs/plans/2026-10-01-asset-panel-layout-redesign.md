# 资产管理页布局重设计 — 设计方案

> 日期：2026-10-01 ｜ 状态：**已实施并验证**（同日 M1–M5 落地；实施备注见 §8）
> 来源：2026-10-01 grilling 会话（Q1–Q9 逐轮收口）。领域术语见 `CONTEXT.md`，相关决策 `docs/adr/0002`、`docs/adr/0003`。
> 前置文档：`2026-09-29-asset-grouped-view-design.md`（分组视图）、`2026-09-30-asset-facets-lifecycle-design.md`（筛选与生命周期）。

## 1. 背景与问题

用户观察：「资产管理面板左边承担太多内容，右边交互不多、只是一个看。」

拆解后坐实**两条根因**：

### 1.1 职责失衡（主因）

- 左栏（`DataSourcePanel.tsx`，1683 行）同时承担**库治理**（导入 / 体检 / 命名 / 状态标记 / 删除）与**浏览挑选**（筛选 / 分组 / 激活）两类工作；资产级操作散落在 hover 按钮（行 2 个、组头 3 个、平铺卡 3 个）与 **15 项右键菜单**（`DataSourcePanel.tsx:1015-1051`）里。
- 右栏（`VehicleListPanel.tsx`，475 行）只承接工作集（「待分析车型」），本体只读。**点选左栏资产后右栏毫无反应**——单击只做高亮；`focusedFile` 在提交 `48fa771` 之前本是"唤出右栏"的触发器，右栏改为常驻后它失去了去向。
- 历史旁证：这个位置曾有"选中对象预览"职责（`DataPreview.tsx`，279 行，现零引用 = 死代码）。

### 1.2 整页滚动 bug（机制性问题，非设计取舍）

- 外壳 `MainLayout` 是 `min-h-screen`（`MainLayout.tsx:150`），`Content` 无高度约束（`:191`），`index.css` / `index.html` 无 `html/body/#root` 高度规则 → 左侧列表一长，**整个文档被内容撑高、整页滚动**；两栏面板的 `h-full + overflow-y-auto`（`DataSourcePanel.tsx:1156-1158`、`VehicleListPanel.tsx:230-248`）因此不生效。
- 后果：右栏购物车锚在文档流顶部，**往下滑即被卷出视口**——「边挑边看」物理上做不到（用户实测确认）；左栏自己的工具栏/筛选行也在滚动容器内部，同样会被滚走。
- 旁证：顶部 Header 特意 `sticky top-0`（`MainLayout.tsx:151`），就是为整页滚动准备的。

### 1.3 派生需求

- **边挑边看是硬约束**：车型多（数百个全展开）、左侧列表长，挑选时必须随时看得到已选工作集。
- 「挑选了哪些」的可见性有两半：右栏购物车（被 1.2 弄丢）与左栏行标记（现为 3px 左色条 `edge-success`，`index.css:287`，且**聚焦会把它顶掉**，`AssetGroupedView.tsx:173-179`）。

## 2. 目标形态（总览）

```
资产管理页（PoolPane 锁定视口高度，两栏各自内部滚动）
┌───────────────────────────────┬──────────────────────────────┐
│ 左：资产库（浏览 / 筛选 / 挑选）  │ 右：工作侧栏（常驻）            │
│ ┌───────────────────────────┐ │ ┌──────────────────────────┐ │
│ │ 工具栏 + 筛选行  ← sticky  │ │ │ 选中资产摘要卡（点选即刷新） │ │
│ │ ───────────────────────── │ │ │ 快操：激活·重命名·标签·     │ │
│ │ ▸ V6E（已选 2）  ⚡        │ │ │      公告对比·详情⟩        │ │
│ │   ├ E6 客运版  ▎已选       │ │ ├──────────────────────────┤ │
│ │   └ E6 货运版              │ │ │ 待分析车型（购物车）已激活 N │ │
│ │ ▸ 大拿V1 …（列表内部滚动）  │ │ │  ├ 车卡：缺必填·对比·移出   │ │
│ └───────────────────────────┘ │ └──────────────────────────┘ │
└───────────────────────────────┴──────────────────────────────┘
   单击行 → 右栏摘要卡刷新 · 深操作 → 「资产检查器」右侧抽屉 · 备选区已移除
```

一句话：**左栏收窄为"浏览 / 筛选 / 挑选"，右栏变成常驻工作侧栏（选中资产摘要 + 购物车），一切对象级操作收进统一的「资产检查器」抽屉。**

### 2.1 决策一览

| # | 决策 | 要点 |
|---|---|---|
| 1 | 视口锁定（只锁 PoolPane） | 两栏各自内部滚动，购物车常驻钉右；外壳与其他 tab 不动；左栏顶栏 sticky |
| 2 | 右栏双段式 | 上=「选中资产」摘要卡（点选即刷新）；下=「待分析车型」购物车 |
| 3 | 「资产检查器」抽屉 | 统一交互面，接收全部对象级操作，取代现有只读详情抽屉 |
| 4 | 左栏减负 | 右键菜单 6 项封顶；hover 精简；组级操作留组头 |
| 5 | 已选可见性 | 行标记常显且与焦点态正交；组头「已选 N」角标；「只看已选」；反向定位 |
| 6 | 备选区移除 | 已过滤是零调用死概念；资产车与左栏重复；本地车归公告中心 |
| 7 | 比例 | 保持 50/50（`48fa771` 既定），双段上线实测后再议 |

## 3. 各区块规格

### 3.1 视口锁定（决策 1）

- **范围**：只锁 `PoolPane`（`ParameterWorkbench.tsx:39-55` 的两栏容器），自持视口高度（≈ `calc(100vh − 头部 48 − Content padding 32 − Footer 41)`，实现时以实测校准）。外壳 `min-h-screen` 与其余三个 tab（对比/填报/净化）的滚动行为**一律不动**。
- **两栏各自内部滚动**；右栏购物车头部（「待分析车型」标题 + 清空 + 已激活 N，`VehicleListPanel.tsx:231-246`）本就在滚动容器外，锁高后天然钉住。
- **左栏顶栏 sticky**：标题/工具栏/治理提醒条/视图与搜索行（`DataSourcePanel.tsx:1159-1266`）在滚动容器内做 sticky；筛选面板与列表随内容滚动。
- 验收：数百车型全展开、滑到深处——购物车始终可见；左栏顶栏不滚走；改筛选无需回顶。

### 3.2 右栏双段式（决策 2）

**上段：选中资产摘要卡**（默认收起，不占位）

- 触发：左栏任意行/卡片**单击即刷新**（点选语义：单击=选中，深操作走检查器；「聚焦查看」不再需要）。
- 内容：短显示名 + `@来源文件` + 状态徽章（最新/历史/废弃/驳回）+ 关键事实一行（公告号 · 完成率 · 必填缺失数）+ 标签 chips。
- 快操：**激活/移出**（按当前态切换）、**重命名**、**标签**、**公告对比**、**详情**（打开检查器）。

**下段：待分析车型（购物车）**

- 保留现状：车卡（短名/来源标签/缺必填/统计徽章/「对比」/「移出」）+ 头部（清空工作区车型、已激活 N）+ 空态提示。
- 点车卡 = **左栏滚动定位 + 短暂高亮 + 摘要卡切换**（反向"边挑边看"）；打开检查器走卡上「详情」按钮。本地车（无左栏目标）点按直接打开检查器。

### 3.3 「资产检查器」抽屉（决策 3）

- **形态**：右侧 Drawer（宽度按参数预览需要定档，520–640 区间）；**统一服务**左栏资产与购物车车辆。
- **入口**：左栏摘要卡「详情」/ 行双击 / 右键「打开检查器…」；购物车车卡「详情」。
- **内容**（自上而下）：
  1. 事实头：显示名/产品名、`@来源文件`、状态徽章、公告号、标签；
  2. 统计区：完成率 / 参数总数 / 有效值 / 空值四卡 + 分组完成度 + 必填缺失（移植现只读抽屉，`VehicleListPanel.tsx:377-469`）；
  3. 参数预览：只读、按需加载资产文件（`loadAssetFile`），与工作集自动加载（`AssetDataSynchronizer`）分工；
  4. 操作区（**从右键菜单整体迁入**）：标签编辑、重命名、标记关键车型/历史版本/废弃（含取消）、复制公告号、查看公告 PDF、与公告对比、导出 CSV、升级导入、在 Finder 中显示、打开文件、删除（可恢复）、彻底删除（归档，条件出现）；对已激活车辆保留「送去对比」。
- **与现有件的关系**：公告对比沿用 `AnnouncementDiffDrawer`；重命名沿用现有 Modal；标签沿用 `TagSelector`；批量打标栏不动。

### 3.4 左栏减负（决策 4）

**右键菜单压缩为 6 项封顶**（现 15 项，`DataSourcePanel.tsx:1015-1051`）：

```
激活/移出工作集 · 在 Finder 中显示 · 重命名 · 批量选择 ｜ 打开检查器…
```

- 「聚焦查看」删除（单击即选中，已冗余）；其余 10 项动作全部只在检查器。
- **行 hover 只留「激活/移出」**（Finder 图标移走，`AssetGroupedView.tsx:232-248`）。
- **组头 hover 不搬**：⚡ 激活组内最新版、重命名车型组、组属性保留（组级操作，检查器是资产级，`AssetGroupedView.tsx:114-135`）。
- **平铺卡片同规则**：hover 只留「激活/移出」（`DataSourcePanel.tsx:1471-1509` 中的重命名/删除进检查器）；**「一键修复命名」保留**（命名不规范高频治理）；内联标签编辑退役（改只读 chips）。
- 工具栏 4 图标（导入/体检/刷新/换目录）、筛选行、批量打标栏、「⚡将筛选结果新增到工作区」链接**均不动**。

### 3.5 已选可见性（决策 5）

- **行级标记强化**：已选行常显且与焦点态**正交**（现 focused 会把 `edge-success` 顶掉，需改为可并存的组合样式，`AssetGroupedView.tsx:173-179`）。
- **组头「已选 N」角标**（现在只有边缘色条）。
- **「只看已选」开关**进视图/筛选行（去对比/填报前复核用）。
- **反向定位**：点购物车车卡 → 左栏 `scrollIntoView` + 短暂高亮（与 3.2 同一条交互）。

### 3.6 备选区移除（决策 6）

**结论：移除「备选/已过滤车型」区块**（`VehicleListPanel.tsx:330-374`）。证据：

1. **「已过滤」是死概念**：写入动作 `toggleIgnoreProduct`（`vehicleStore.ts:295`）全 UI 零调用方；`ignoredProductNames` 仅 `VehicleListPanel`（删除线展示）与会话持久化在读。
2. **「备选」三种车混装**：①未选中的本地文件车型——今天的写入方只剩公告中心拉取的对比数据（`AnnouncementQuery.tsx:134,238`）与已死抽屉（`AssetListDrawer.tsx:69`）；②被移出工作集的资产库车型——与左栏完全重复（左栏才是选择器，行上就有 +）；③死掉的忽略项。

**实现边界**：先只删 UI；`ignoredProductNames` 状态与 session 字段暂不动（零风险，字段清理另立小活）。本地车型移出后无池内回归入口，可接受——公告数据在公告中心重拉，池页从此只认资产库。

### 3.7 比例（决策 7）

- 保持 50/50（`48fa771`「永久 50/50，移除条件触发」为既定决策；双段后右栏内容增多，对称仍成立）。
- 双段式上线实测后若感到拥挤再议（含可拖拽分隔条的重新评估）。

## 4. 评审提示（3 条推断项，请确认）

以下三条是从已定决策推导的补充，评审时重点看一下：

1. **平铺卡片同规则**：hover 只留激活/移出，重命名/删除进检查器，内联标签编辑退役（改只读 chips）；「一键修复命名」保留。

## 6. 实施顺序建议（供确认后开工）

> 每个里程碑结束跑 `npm run lint` + `npm run test` + `npm run build`；逻辑改动必须三条全跑。

- **M1 视口锁定（底座）**：PoolPane 锁高 + 两栏内部滚动 + 左栏顶栏 sticky。
  验收：数百车型全展开滑动，购物车始终可见；顶栏不滚走。
- **M2 已选可见性**：行标记正交 + 组头角标 + 「只看已选」+ 反向定位。
  验收：深列表滚动中已选行可辨；购物车点车定位准确。
- **M3 资产检查器**：统一抽屉（左资产 + 购物车车辆）+ 动作迁移 + 左栏瘦身（右键 6 项 / hover / 平铺规则）。
  验收：原 15 项动作全部经检查器可达；右键菜单 ≤6 项且高频可完成激活/重命名/Finder。
- **M4 右栏双段**：摘要卡（点选联动 + 快操）+ 购物车调整（点卡定位、本地车 fallback）+ 备选区移除 + 旧只读抽屉退役。
  验收：点选任意资产摘要卡即刷新；备选区消失无死角；本地车行为自洽。
- **M5 收尾**：P2 可选项评估、文档回填、真机全量回归（含暗色模式）。

## 7. 实施注意（约束清单）

- **`AssetGroupedView` memo 契约**：handler 闭包不参与比较 + 原生 `title`（`AssetGroupedView.tsx:140-146`）勿破坏；新增行内状态（已选标记正交等）走数据 props。
- **批量保存走 Rust** `save_assets_batch` 单 IPC；本条不涉 Rust 改动；若检查器参数预览需要新 Rust 命令，改完必须重启 dev（否则静默回退 JS 慢路径）。
- **入库 ≠ 加入工作区**：`addActiveAsset` 不得从导入链路加回；本设计不改导入。
- **WebKit**：sticky 在滚动容器内是标准场景；PoolPane 锁高后该页不再整页滚动，无冻结列残影前提；但列表卡片自持高度等 canonical 写法（见 `MultiVehicleView`）不要退化。
- **状态兼容**：`ignoredProductNames`、视图模式（`asset-panel-view-mode`）与展开集合（`asset-panel-expanded-groups`）localStorage key 均不动。
- **异步数据**：检查器参数预览按需 `loadAssetFile`，注意与 `AssetDataSynchronizer`（只加载工作集）互不干扰；加载态用骨架屏。
