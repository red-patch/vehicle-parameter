# 数据体检 — 参考车型「视同更新」设计方案

> 日期：2026-10-15 ｜ 状态：已实施
> **修订（2026-10-19）**：§3.3 的参数名维度与 §3.4 的 `name ← 参考名` 已废止——参数名改为只读，
> 视同更新只对齐参数值与分组。见 `2026-10-19-参数名只读-design.md`。
> 关联：`docs/adr/0002-identity-key-and-no-silent-overwrite.md`（永不静默覆盖——视同更新必须显式触发并可见差异）、`src/components/DataPurify/DataPurifyView.tsx`（本设计的落点）
> 领域术语见 `CONTEXT.md`（资产 / 受控属性 / 身份键）。

## 1. 背景与问题

体检页的工作流是「一个车型 × 一堆异常字段」的手工循环。切到某车型，把 28 条异常逐个改掉，保存；换下一个同系列车型，发现它有**同样的 28 条异常**，只能再点一遍。重复劳动的量级是「车型数 × 字段数」。

诉求原文：

> 数据体检跟修复页面有个场景是同类车型只有几个字段不一样：第一个车型修复之后，第二个车型还要重复点击很多字段进行修改。能否在这个数据体检页面指定某个车型作为参考，然后快速点击字段做视同更新？

## 2. 目标与非目标

**目标**：把体检从「逐字段人工录入」变成「以已校准车型为模板的批量对齐」。指定一个参考车型后，当前车型的差异行可一键（或全量一键）采纳参考值。

**非目标**：
- 不做模糊候选推荐（未匹配行给候选让你挑）。同系列车型的命名差异基本是空格/括号，容错匹配已覆盖。
- 不做「保存后自动把参考切到刚修的车型」。参考车型由用户显式选择并记忆。
- 不做组内差异视图 / 按分组折叠（现有筛选栏已有分组下拉）。
- 不自动保存：沿用本页「改完统一保存」的既有节奏（覆盖原资产 / 单独保存）。

## 3. 设计

### 3.1 参考车型的数据来源

参考车型的数据**从 store 读已保存的资产/上传数据**：

```
getVehicleSelectionState(uploadedFiles, refKey, assetFiles, activeAssets).data
```

**不走 `purifyParams`**——`purifyParams` 只装当前待体检车型，且切车型时会被重置。

由此得出一条边界：参考值永远是**已保存**的值。流程是「修好 A → 保存 → 切到 B」，保存已同步刷新 `assetFiles`，参考随即含新值。未保存就切车型本来就会丢改动，不新增提示。

参考车型 == 待体检车型时，整个对比功能自动禁用（自己跟自己比无意义），参考下拉禁用该项。

### 3.2 字段对齐（纯函数层 `src/utils/vehicleFieldDiff.ts`）

```
normalize(name) = trim → 全角空格/全角括号转半角 → 去除所有空白字符
```

因此 `前视行车记录仪（DVR）`、`前视行车记录仪 (DVR)`、`前视行车记录仪(DVR)` 三者互认。

匹配两级：

1. **精确名优先**——查 `Map<原始名, 参数>`
2. 未命中再查**归一化名索引** `Map<归一化名, 参数>`，同键冲突取先出现者

两边都没命中 → 该行无参考值，不显示同步按钮。

### 3.3 差异判定

三个维度任一成立即为**差异行**：

| 维度 | 判为差异的条件 |
|---|---|
| 参数值 | 参考值非空，且与当前值不同（当前为空也算） |
| 参数名 | 当前名 ≠ 参考名（含归一化后相同但字面不同的情况） |
| 分组 | 当前分组 ≠ 参考分组 |

参考值为空的行永不算差异（避免把「参考车型也没填」的字段当成差异来覆盖）。

纳入名和分组的理由：只按值判的话，「倒车影像 」vs「倒车影像」这种只差空格、值相同的行就无法一键改正名。

### 3.4 写入行为

点「视同」一次性写入三个字段 + 时间戳：

```
name ← 参考名    value ← 参考值    group ← 参考分组    updatedAt ← 当前时间
```

同步后该行自然不再是差异行，表格即时重渲染。同名多行各自独立匹配、各自独立同步。

## 5. 状态

store 新增 `purifyReferenceProduct` / `setPurifyReferenceProduct`，进 `partialize` 持久化到 localStorage（与 `poolSidebarWidth` 同类：短字符串）。资产被删除时（`removeAsset`）若命中参考车型则清空。参考车型**记忆但不自动刷新**——保存完 A 不会自动把参考切成 B。

## 6. 测试

对齐仓库现状（utils 纯函数测试，无组件测试）：

`src/utils/__tests__/vehicleFieldDiff.test.ts`
- 精确匹配 / 归一化匹配（括号、空格、全角）
- 参考值为空 → 不算差异

- 两边都无同名 → 无差异

验证：`npm run lint && npm run typecheck && npm run test && npm run build` 全跑。

## 7. 权衡

**采纳**：差异判定含名与分组（而非只判值）；行级 + 全量两级按钮；差异只在参考值非空时成立。

**放弃**：模糊候选推荐（多一层交互，收益低）；保存后自动切换参考（失控）；按分组折叠的差异视图（与现有分组下拉重复）。
