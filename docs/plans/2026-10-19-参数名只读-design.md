# 数据体检：参数名只读（视同更新只对齐值与分组）— 设计方案

> 日期：2026-10-19 ｜ 状态：已实施
> 修订：`2026-10-15-体检参考车型视同更新-design.md`（原文把参数名也作为差异维度并写回）
> 关联：`docs/plans/2026-10-13-batch-field-maintenance-design.md`（字段来源限受控词表）、`src/components/DataPurify/DataPurifyView.tsx`

## 1. 背景

用户质疑：「数据体检模块的参数名是不能支持修改的，怎么还能支持改啊？」

核查结论：**当时确实可改，而且是按可改设计并写进文档的**——

| 位置 | 原行为 |
|---|---|
| `DataPurifyView.tsx` 参数名列 | 点开变输入框，可自由输入 |
| 同列警告图标 | 「推荐的标准字段名」弹窗，点一下直接改参数名 |
| `User_Manual.md` §6.4.1 | 「可编辑项」明确列出参数名 |
| 「视同更新」 | 把参考车型的参数名一并写回 |

但参数名是**跨车型比对、字段组取数、公告比对、智能填报匹配**的键。工具内自由改名会：
造出同义重复字段（「整备质量」/「整车整备质量」），让同一个事实在资产里出现两份；
让字段词表与实际数据持续漂移，且漂移没有溯源。

## 2. 裁定

1. **数据体检里参数名只读**：去掉点开编辑与推荐弹窗；参数名只来自导入的源数据。
2. **「手动新增参数」改为从字段词表选名**：既然是新增一行，名字只能取自受控词表；
   词表未配置时该入口禁用并说明原因。
3. **「视同更新」只对齐参数值与分组**：差异判定不再看参数名；参数名永不写入。
4. **非标准字段名仍然告警**：信号保留（标橙 + 快捷筛选 chip），只是不再提供就地改名的出路；
   修正路径是回到源数据/重新导入。

## 3. 影响

- 只差名字（如「倒车影像 」vs「倒车影像」）而值与分组相同的两车字段，不再算差异行。
- 想改名的用户必须回到源数据：资产 JSON 外部编辑，或修正源 Excel 后重新导入。
  工具内不再提供改名入口。
- 「字段组」筛选、搜索、修复任务定位都按名字匹配，行为不变（名字只是不再被本页写）。

## 4. 代码落点

| 位置 | 改动 |
|---|---|
| `src/utils/vehicleFieldDiff.ts` | `RowDiff` 去掉 `nameDiffers`；`buildSyncPatch` 只返回 `value`/`group` |
| `src/components/DataPurify/ReferenceSync.tsx` | 文案不再提参数名 |
| `src/components/DataPurify/DataPurifyView.tsx` | 参数名列改纯文本 + 告警 Tooltip；编辑态联合类型去掉 `name`；新增参数改为词表选择 |
| `docs/User_Manual.md` / `User_Manual_Lite.md` | 可编辑项与操作步骤同步 |
| `docs/PRD.md` | 版本记录补一条 |

## 5. 测试

- `src/utils/__tests__/vehicleFieldDiff.test.ts`：名字不同而值/组相同 → 非差异；同步补丁不含 `name`。
- `src/components/DataPurify/__tests__/DataPurifyView.readonly-name.test.tsx`：
  点击参数名不出现输入框、无「推荐的标准字段名」入口。

## 6. 验收

1. 数据体检里点击参数名单元格，不出现输入框。
2. 非标准字段名仍标橙、仍进入「字段名不在词表」筛选。
3. 选参考车型后点「视同」，参数名保持不变，参数值与分组对齐。
4. 未配置字段词表时，「手动新增参数」不可用。
