# 对比视图「按字段名合并」— 设计方案

> 日期：2026-10-09 ｜ 状态：**已实施并验证**
> 来源：用户实操反馈。截图中三台同源车型（远程 V8E 货运版 / 同一公告号的两个版本）参数实际一致，却因导入时归属总成不同（「迎风面积 (m²)」一台落在「空气动力学」、两台落在「基础信息」）被拆成两行，各显示一半有值、一半为 `-`，被判为"差异"。
> 关联：`docs/adr/0002`（身份键与永不静默覆盖）、`CONTEXT.md`（领域术语）、`AGENTS.md`（纯函数优先放 `src/utils/`）。

## 1. 问题

[CompareView](../../src/components/ParameterWorkbench/CompareView.tsx) 的行键是 `分组::参数名`：

```ts
const key = `${group}::${p.name}`;
```

这条规则**是故意的**（源码注释已说明）：防止不同总成下的同名参数（如各传感器都叫「型号」）互相覆盖——若只按 `name` 建键，一台车的多行会互相覆盖，跨车对比会拿错总成的值。

但它的代价是：**同一台车在不同导入批次里被归到不同总成的同一字段，会被当成两个不同字段**，于是显示"半边有值半边空"，产生假差异。

## 2. 目标与非目标

**目标**：给用户一个可选的「按字段名合并（忽略分组）」开关，让上述场景合并成一行、如实显示为"一致"。

**非目标**：
- 不改默认行为（默认仍按 `分组::参数名`）。
- 不做字段名归一化（不去括号/单位），v1 只按**精确 `name`**（去首尾空白）匹配。归一化会把「外形尺寸长(mm)」与「外形尺寸长」这类也可能有别的差异的字段并到一起，风险大于收益，留作后续可选项。
- 不合并同一台车内本身就冲突的行（见 §3 规则 A）。

## 3. 规则

新增开关 `mergeByFieldName`（默认 **false**）。

**规则 A（有冲突即不合并）**：某字段名只要在**任一选中车型**内存在 ≥2 个**不同非空值**，该字段名整体不合并，退回 `分组::参数名` 的原有行为。

即：**只在合并不会产生歧义时才合并**。这与 ADR-0002「永不静默覆盖」一致——宁可多显示一行，不在数据层替用户做业务取舍。

合并成立时：

| 行属性 | 取值 |
|---|---|
| `key` | `name`（前缀标记，避免与未合并键碰撞） |
| `group` | 各车该字段名归属总成去重后：仅 1 个 → 该总成；≥2 个 → `多组` |
| 各车值 | 该车该字段名的唯一非空值（全空则为空） |
| `hasDiff` | 按合并后的各车值判定，与未合并时同一套逻辑 |

## 4. 实现

矩阵构建逻辑从 `CompareView` 的 `useMemo` 内联代码抽到独立纯函数，便于单测：

- 新增 `src/utils/compareMatrix.ts`：
  - `CompareRow` 类型（从 CompareView 迁出，附加可选 `groups: string[]`）
  - `buildCompareRows(inputs, { mergeByFieldName })` —— `inputs` 为 `{ instanceKey, params }[]`
- `CompareView` 只负责：取值、调 `buildCompareRows`、渲染。开关放在「隐藏无值字段」旁，文案 **「按字段名合并」**。
- `group` 单元格：`多组` 时用 `Tag` 区别显示（可后续加 Tooltip 列出具体总成）。

`compareReport` 的导出沿用现有行结构，新增字段为附加信息，不破坏现有报告。

## 5. 验证

- 新增 `src/utils/__tests__/compareMatrix.test.ts`（纯函数，TDD 先行）：
  1. 关闭开关 → 与现有 `分组::参数名` 行为逐字一致
  2. 开启 + 同名同总成跨车 → 合并单行
  3. 开启 + 同名不同总成、每车单值 → 合并单行，`group === '多组'`
  4. 开启 + 某车同名跨总成且值冲突 → **不合并**，退回两行（规则 A）
  5. 空值不覆盖已填值（沿用现有语义）
  6. `hasDiff` / `hasAnyValue` 在合并后正确
- 既有 `CompareView.groupKey.test.tsx` 必须继续通过（默认行为不变）。
- 跑 `npm run lint && npm run typecheck && npm run test && npm run build`。

## 6. 边缘情况

- 单车型对比（`localSelection.length === 1`）：`hasDiff` 恒为 false，合并只影响分组显示，无副作用。
- 所有车值都为空：合并后仍是空行，由「隐藏无值字段」决定是否显示。
- 搜索结果里 `group` 显示为 `多组` 时，按 `多组` 关键字可搜到。
