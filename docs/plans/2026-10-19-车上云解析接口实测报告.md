## 1. 接口结论

| 项 | 结果 |
|---|---|
| 端点 | `POST /dst-apis/1/operateBasic/productAccess/finish/parseTemplate?templateId=&basicId=` |
| 鉴权 | 请求头 `token`（= 登录后 cookie 里的 `token`）；缺失 → `1000 令牌不可为空`，失效 → `1001 令牌验证不通过` |
| 必填参数 | **`templateId` 必传**，缺了返回 `500 Required Long parameter 'templateId' is not present` |
| 请求体 | `multipart/form-data`，字段名 `file` |
| 成功响应 | `{"status":true,"code":"200","data":[...]}` |
| 异常响应 | `code:"1021"`，`msg` 是**数组**：`[{key:"第[N]行", msg:"..."}]`；N 与上传文件行号一一对应（表头为第 1 行） |
| 复用性 | 脚本已落在 [scripts/verify_dstcar_template.ts](../../scripts/verify_dstcar_template.ts) |

用法（token 一次性，不要落盘提交）：


## 3. 对照实验：换成官方空白模板填同样值

用 `downloadTemplate` 取到官方模板（432 行），按字段名填入同一批值后再传：

- 异常从 **41 条降到 18 条**
- 消失的正好是 12 条「列不属于该模版」+ 「出厂前装易流温度监测设备」定位
- 剩下的 17 条与 §2.2 / §2.3 完全吻合（不含 285 那对同义重复）

→ 证明：**列被拒的唯一原因是多导出了裸名，不是文件格式问题**；取值与必填问题是真·数据问题。

## 4. 额外发现（本地全量枚举扫描：15 处越界，其中 5 处服务端未报）

服务端本次返回 41 条即止，本地按模板全量枚举比对（含 `出厂…` 名）还能捞到 5 处服务端没报的：

| 行 | 字段 | 值 | 说明 |
|---|---|---|---|
| 44 | 出厂货厢内部高度（mm） | 1475 | 模板枚举无此值（有 1455/1465/1460…） |
| 46 | 出厂货厢内部长度（mm） | 3280 | 模板枚举无此值 |
| 191 | 交流充电时间（常温,SOC:20%-100%）（h） | ≤10 | 枚举是「10-11」「10-12h」这类区间 |
| 261 | 慢充（kw） | 6.6；无 | 多值应用 `;` 或 `,` 分隔的单值，枚举里只有 `6.6` 与 `无` |
| 362 | 直流充电时间（常温,SOC:20%-100%）（h） | ≤0.8 | 枚举是「1h」「1-2」这类区间 |

另：文件行 251 `冷厢左&amp;右&amp;后侧壁填充材质/厚度（mm）` 是从官方模板抄来的、**模板自身就把 `&` 转义成了 `&amp;`**，所以传上去反而能对上；这是车上云模板的缺陷，不是我们的（该行值为空，未触发校验）。

## 5. 对产品化的含义

1. **接口不能在前端直接调**：`OPTIONS` 预检返回 403，没有 CORS 放行；且 token 是车上云登录态，极短有效期。真要做「上传即体检」，只能走 Tauri 端（Rust 侧带用户 token 转发），或干脆按 §4 的模板枚举做**离线体检**（零登录、零网络、结果可复现）。
2. 离线体检（模板字段集 + 枚举 + 必填清单入库）可覆盖本案 **全部 41 条**，还能多抓服务端没报的 5 处枚举越界；唯一需要额外做的是「模板必填但文件整行缺失」（`出厂尾板状态`），只要把模板必填清单一起入库即可。模板共 33 个必填项。
3. 本次数据再次印证设计文档 §1 的结论：**按字段组收敛输出、同义双写只留模板要的那个名字**是导出能否被接受的分水岭。实测上，删掉 12 行裸名即可消掉 12 条列报错，剩余 17 条是真实数据问题（10 取值 + 7 必填），与文件格式无关。

### 待确认（语义判断，需业务确认）

- `侧门帘`（第 17 行 = 右侧滑门）和 `尾门帘`（第 315 行 = 对开门）：模板枚举只有 `标配 / 无 / /`，看起来是**帘布的有无**，而不是门的形式。若确属「把门型填进了帘布字段」，应改为 `无`（或实际状态），而不是给值找枚举。
- `出厂尾门开启度数（°）`（第 312 行裸名那条）文件值是 `270`，模板枚举里 `270` 与 `270°` **并存**，选哪个都能过；按现有数据保留 `270` 即可。
