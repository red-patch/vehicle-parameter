# 车型资产数据治理方案：主文件标注与快速定位

> 日期：2026-09-28　状态：已实施
> 背景：生产环境车型数据库（`/Users/ethan/车型数据库`）中一个车型有多个数据条目（不同版本、准入/开发级别不同），需要能标注并快速定位"主要车型文件"。

## 1. 数据现状（2026-09 摸底）

- **规模与形态**：262 个文件全部平铺在资产库根目录（无子目录），全部为本工具导出的资产 JSON（`AssetFileFormat`），共 44MB。
- **数据级别**：约 211 个为公告/准入级（来源 `产品准入导出*`，内部带 `准入信息` 参数组，含 `产品等级标准` Ⅰ~Ⅳ、`准入编号` ZRYYYYMMDDNNNN、`整车公告号`、`审批状态` 已审核/驳回）；约 57 个为开发/配置级（来源 `附件一《车辆配置清单》`/`Sheet1`/早期手工录入）。驳回件未删除，与重报版并存（如 ET50 ZR202511060002 驳回 与 ZR202511060003 重报并存）。
- **命名乱象**：至少六种范式并存（公告范式 `车型 供应商 电量 公告号 等级`、短横线手工范式、下划线日期戳、新石器牌下划线范式、自由发挥、`【废弃】`前缀）。分隔符（空格/`-`/`—`/`_`）、供应商全称简称、电量尾零、年款写法均不一致；存在疑似错别字（`重创新航`）。
- **重复表现**：
  - 同一公告号多次准入申报：全库 11 组（如 智云S300 SX5045XXYBEV341N 先后 3 份 ZR 申报）。
  - 跨代际/跨范式重复：V6E 家族 20+ 个文件；大拿V1 同一 VIN 级配置的新旧两版（3 月 63 参数简版 vs 5 月完整版）。
- **已有设施**：`_asset_tags.json` 标签旁路（251 条）、`custom_asset_tag_groups.json`（已定义 `准入等级` Ⅰ~Ⅳ、`车型族群`、`厂商` 标签组）、`assetNaming.ts` 命名规范扫描（五段式 + 一键修复）。**缺**：主文件标记、级别识别、状态标记、分组定位。

## 2. 治理模型

每个文件两层属性：**自动派生**（扫描时计算，不落盘）+ **人工标注**（存旁路文件 `_asset_meta.json`）。

| 维度 | 来源 | 值 |
|---|---|---|
| 数据级别 | 自动派生：参数含「准入信息」组 | 🏛 准入 / 🛠 开发 |
| 审批状态 | 自动派生：`审批状态` 字段值 | 已审核 / ⚠ 驳回 |
| 主文件 👑 | 人工标注（体检自动建议 + 人工确认） | `isPrimary`，同车型组内原则唯一 |
| 历史版本 🕘 / 废弃 🚫 | 人工标注（只打标，不隐藏、不移动） | `status: 'superseded' \| 'deprecated'` |

### 存储格式

`_asset_meta.json`（`_` 前缀保证 Rust/JS 扫描天然跳过，不会混进车型列表）：

```json
{
  "<fileName>.json": { "isPrimary": true },
  "<fileName>.json": { "status": "deprecated", "note": "驳回件" }
}
```

重命名（`renameAssetFile`/`renameAssetIdentity`）与删除（`deleteAssetFile`）时同步迁移/清除，与标签同步同款逻辑。

### 车型分组键（主文件唯一性的作用域）

`deriveVehicleGroupKey`（`assetGovernance.ts` 纯函数）：

1. 剥 `【…】` 前缀、`.json` 后缀；
2. 命中五段式命名规范 → 取 `series`；
3. 否则取首个 token（空格/`-`/`—`/`_` 分隔），依次剥离尾部括号内容（`V6E（客运版）`）、厂商前缀（厂商名单 = 标签组「厂商」∪ 内置兜底名单，如 `金旅ET850 → ET850`）、变体尾缀（`客运版/货运版`）；
4. token 被剥空时（`新石器牌_X3_…`）顺延取下一个 token；
5. 拉丁部分归一大写。

启发式不追求 100% 准：设主文件遇组内冲突时弹确认"替换"，旧主文件自动取消标记（不自动打历史标）。

### 主文件建议规则（确定性）

组内排序取第一：文件名带「废弃」降级 → `审批状态=已审核` 优先 → `filledParams` 最多 → `updatedAt` 最新 → 文件名字典序兜底。

## 4. 日常使用

- **首次治理**：点资产面板头部 `📋 治理体检` → 逐组/全部"采纳建议" → 组内已审核、参数最全、最新的文件自动标 👑；对确定废弃的旧件右键标 🚫。
- **日常定位**：列表主文件自动置顶；`👑 只看主文件` 一键过滤；徽章区分 准入/开发（来源标签）、驳回（自动）、历史/废弃（标注）。
- **新文件进来**：导入保存后在体检里看新组建议；驳回件由扫描自动带 ⚠ 徽章，无需手动标。

## 5. 后续路线（未实施）
