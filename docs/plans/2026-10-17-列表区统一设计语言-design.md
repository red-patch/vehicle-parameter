# 列表区统一设计语言（工具条 · 搜索 · 内容 · 尺寸 · 字号 · 行高）— 设计方案

> 日期：2026-10-17 ｜ 状态：**已实施**
> 来源：用户「把各业务页面的列表区（工具栏按钮、搜索、内容、列表大小、字体大小、行高）系统化统一成一套设计语言」
> 关联（本文**扩展**而非推翻）：
> - `2026-10-15-ui-构件规范-design.md`：控件形态（SearchInput / FacetChips / FilterItem）与护栏 R1–R10
> - `2026-10-16-列表页设计语言-design.md`：ListToolbar 三段槽位、primary 只给产出动作
> - `2026-10-16-表格行规范-design.md`：一格一主控件、CellText、`size` 收敛
>
> 前两轮定下了「**结构**」（几行、每行放什么），本轮定下「**度量**」（多大、多高、多粗、多密）——
> 结构一致而度量各异时，页面依旧「长得不一样」。

## 1. 现象：结构已统一，度量还在各说各话

以 9 个列表视图实测（截图脚本逐页量 `th` / `td` 高度、字号、按钮尺寸，mock 数据）：

| 维度 | 实测分布 | 来源 |
|---|---|---|
| 表格行高 | 38 / 41 / 42 / 49px 四种，同一张表内 38 与 41 交替 | `size` small/middle 混用 + 行内控件撑高部分行 |
| 表头高 | 36 / 44px | 同上 |
| 面板标题字号 | 13 / 14 / 15px，字重 400 / 600 / 700 | 各页自写 `<span className=…>` |
| 计数写法 | 「共 26 项」/ 蓝 Tag「已选 3 款」/ 灰 Tag「显示: 17 条」/ 两个 Tag「6 个字段 / 6 激活」/「记录（1）」 | 无约定 |
| 工具条按钮 | 24 / 32 / 40px 三档，同一行内混排（如「导出报告」32 旁边是 24 的图标按钮；「保存并应用」large 40） | 无约定 |
| 行内操作 | link 图标 / 红色 danger 图标 / 带字链接 / 裸图标 | 无约定 |
| 状态列 | antd 预设色 Tag（green/gold/red…，暗色不翻转）/ 纯文本 / 自写圆点 | 无约定 |
| 分页 | pageSize 6 / 8 / 10 / 15 / 20 / 50 六种字面量散落 16 处；有的带切换器有的不带 | 每处字面量 |
| 最小字号 | Tag / 计数 / 年份 10px（`text-[10px]`、`fontSize: 10`，及 antd 推出的 `fontSizeSM`） | antd `fontSizeSM` 由算法推出 10px，跌出阶梯 |
| 面板投影 | 有的 `shadow-sm`，有的没有 | 无约定 |

根因与前三轮同构：**度量没有单一来源**，每个页面在 antd 默认、Tailwind 任意值、手写 style 之间各取一个。

## 2. 全局度量：唯一来源

### 2.1 来源与流向

```
index.css（--fs-* / --font-sans / --info / --table-*-h）   ← 唯一来源
   ├─ tailwind.config.js：text-caption / text-aux / text-body / text-title → var(--fs-*)
   └─ themeConfig.ts：FONT_LADDER / FONT_SANS / TABLE_DENSITY → antd token
```

- antd `fontFamily` = `FONT_SANS` = `--font-sans`（此前 antd 用不含中文字体的西文栈，表格与正文字形不一）
- 亮色 `colorInfo` = `#0E7C8C` = `--info`（此前误用品牌主色，信息态与主按钮撞色）
- 全局 `ConfigProvider`：`button.autoInsertSpace = false`（两字按钮不再被拉成「查 询」），`empty.image = SIMPLE`

### 2.2 字号阶梯（随用户字号档位整体平移）

| 档 | 用途 | 12 档 | **13 档（默认）** | 15 档 |
|---|---|---|---|---|
| caption | 角标、极次要标注 | 10 | 11 | 12 |
| aux | 副信息、`.cell-sub`、计数 | 11 | **12** | 14 |
| body | 正文、表格单元格、筛选标签 | 12 | **13** | 15 |
| title | 面板 / 列表标题、Card 标题 | 13 | **14** | 16 |

- antd `fontSizeSM` 强制 = aux 档（不再是算法推出的 10px）
- **禁止低于 caption 档的字面量**（`text-[9px]` / `text-[10px]` / `fontSize: 10`）→ 护栏 R14
- 表格单元格字号 = body 档，三种 `size` 一致；数字列 `tabular-nums`

## 3. 密度：只有一档

| 项 | 值 | 说明 |
|---|---|---|
| 行高 | **40px**（`--table-row-h`） | 上下 7 + 行内控件 24（`controlHeightSM`）+ 1px 分隔线 |
| 表头高 | **36px**（`--table-head-h`） | 表头比行略紧，层级靠底色与 `text-2` 区分 |
| 单元格内边距 | 7 / 8px（`TABLE_DENSITY`） | small / middle / large 三种 `size` **取同值** |
| 表头文字 | `text-2`，与单元格同字号 | 不再加粗加大 |

### 3.1 为什么让三种 size 取同值

`表格行规范 §3.3` 要求「数据表格统一 `size="small"`」，但那是**靠人守**的；本轮改为**结构性**：
`themeConfig` 让 small / middle / large 的 `cellPadding*` 与 `cellFontSize*` 相同，
于是写不写 `size`、写哪个，行高都是 40——**写不出第二种行距**。

### 3.2 与 `表格行规范` 的关系

- 该文 §1 记录的「数据体检 ~44px」是当时实测，本轮统一为 40px（行内控件 24px 时恰好不撑高）。
- 该文 §3.1 的「文本格补到 24px 与控件格等高」继续有效，并由 `td { height: var(--table-row-h) }` 兜底。
- 「一格一主控件」不变（见 §7）。

### 3.3 表格不画竖线

`bordered` 一律去掉（护栏 R11）。列与列之间靠对齐与留白区分；竖线在 40px 行高下是噪音，
且与 ListToolbar 外壳的边框叠成双线。

## 4. 容器

- 列表区外壳 = `ListToolbar`（根类 `.list-shell`）：1px 边框、圆角 8、**无投影**（护栏 R13）
- 表格贴边（`padded={false}`）：`.list-shell` 内表格圆角归零，避免内外两层圆角错位
- 弹窗 / 抽屉内的表格不套外壳，只遵守 §3 密度与 §6 分页

## 5. 工具条

### 5.1 按钮

- **尺寸两档**：工具条控件（按钮、Select、SearchInput、Segmented）一律 **default 32px**；
  表格内控件一律 **small 24px**（`DataTable` 内包 `ConfigProvider componentSize="small"`，调用方不必逐个写）
- **≤1 个 primary，且只给产出动作**（沿用 `2026-10-16 §5.1`）：智能填报 / 多车型整理的「导出」、
  标书取数的「导出」下拉是 primary；字段与词表的「新增业务字典」、法规库的「保存」不是产出，用 default
- **≥3 个次级动作收进「更多」**（`MoreOutlined` 图标按钮，`aria-label="更多操作"`），且放在最右
- 刷新 = 图标按钮 + Tooltip，置于「更多」之前

### 5.2 计数

计数是**文字**不是标签：标题后一段三级文字（`ListToolbar count`）。

```
法规标准  26              ← 未筛选
法规标准  17 / 26         ← 筛选后（悬停：显示 17 条，共 26 条）
```

- 实现：`formatListCount`（`common/tablePresets.ts`）
- 短标签带数（Segmented 选项、Checkbox 文案）用 `CountLabel`：`全部 26`，数字降不透明度、等宽，**不用括号**
- 标题传字符串时由 ListToolbar 统一排版：title 档 / 600 / `text-1` / 无图标；补充信息（库路径等）走 `subtitle`

### 5.3 筛选行顺序

```
[维度筛选（FilterItem 带标签）· FacetChips · Segmented]              [SearchInput]
```

- 维度在左、**搜索在右，且不带「搜索：」标签**（placeholder 已说明搜什么；标签只给维度）
- `FilterItem` 标签：常规字重、`text-2`、body 档——它是控件说明，不是标题
- 「清除筛选」= link 按钮，仅在有筛选时出现

## 6. 分页：只有两种预设

| 预设 | 用在 | 每页 | 切换器 | 单页时 |
|---|---|---|---|---|
| `pagePagination()` | 页面主列表 | **50** | 20 / 50 / 100 | 显示「共 N 条」 |
| `compactPagination()` | 弹窗 / 抽屉 / 展开行 | **20** | 无 | 隐藏 |

- 弹窗内纵向滚动统一 `MODAL_TABLE_SCROLL_Y = 360`
- 禁止 `pageSize: <数字字面量>`（护栏 R12）；`DataTable` 默认即 `pagePagination`

## 7. 单元格内容

- **一格一主控件**（沿用表格行规范 §3.2）。数据体检「值」列改为**点击编辑**：
  只读态是 `cell-edit-text` 文本，点开才是 Select / Input（`defaultOpen`），不再常驻下拉框
- 副信息（年份、版本、来源）用 `.cell-sub`：aux 档 + `text-3`，与主文本同格不另起行
- 数字列右对齐（`NUMERIC_COLUMN`）+ 等宽
- 空值统一 `—`（全角破折号），不用 `-` / `N/A` / 空白

## 8. 行内操作：`RowActions`

| 规格 | 值 |
|---|---|
| 形态 | `type="text" size="small"` 图标按钮，必带 Tooltip + `aria-label` |
| 露出数 | 最多 `maxVisible`（默认 2）；多 1 个时不折叠（「更多」本身也占位），多 2 个及以上收进「更多操作」 |
| 破坏性 | 常态中性色、悬停转红（`.row-action-danger`）——满屏红色垃圾桶是噪音；需确认时传 `confirm` |
| 带字 | `showLabel` 只给「这一行的主要去向」，一列最多一个 |
| 禁用 | 保留占位，`disabledReason` 作 Tooltip，行间按钮位置不跳 |
| 冒泡 | 点击不冒泡到行（行点击常用于选中 / 展开） |

## 9. 状态与标签

- **状态 = `StatusDot`**（6px 圆点 + 文字）：语义档只开放 `success / warning / danger / info / neutral`，
  颜色取 CSS 变量，暗色自动翻转。取代 antd 预设色 Tag（一整列绿底绿字 = 颜色成了填充而不是信号）
- **分类标签**（主题域、来源类型）用中性 Tag；不承载状态语义
- **数字不进 Tag**（计数见 §5.2）
- 空状态：纯展示用 antd `Empty`（全局 SIMPLE 图）；前置条件未满足用 `GuideEmpty`
- 加载：`Spin` 默认尺寸，不再 `size="small"` / `large` 各写各的

## 10. 落地范围

主列表页：数据体检、版本对比、公告查询（平铺 / 分组 / 归档）、法规标准、字段与词表、
标书取数、多车型整理、智能填报（匹配结果）、差异比对；弹窗 / 抽屉内表格 9 处切到 `compactPagination`。

**不动**：资产池布局（流体多列 / 浮动购物车 / 导航浮窗）已由 2026-10-13 系列文档冻结，
其字号残留登记在 `LIST_LEGACY_EXEMPT`，只减不增。

## 11. 护栏（`src/__tests__/uiConsistency.test.ts`）

| 规则 | 判红条件 | 改为 |
|---|---|---|
| R11 | `<Table` / `<DataTable` 上写 `bordered` | 去掉（§3.3） |
| R12 | `pageSize: 数字字面量` / `pageSize={数字}` / `[pageSize] = useState(数字)` | `pagePagination()` / `compactPagination()`（§6） |
| R13 | 组件源码里出现 `shadow-sm` | 面板无投影（§4） |
| R14 | `text-[9px]` / `text-[10px]` / `fontSize: 9|10` | `text-caption` / `var(--fs-caption)`（§2.2） |
| R15 | `var(--xxx)` 引用了 index.css 未定义的变量 | 用已定义的 token（此前 3 处引用不存在的变量，浏览器静默回退） |

- R11–R14 走「存量豁免 + 增量强制」：`LIST_LEGACY_EXEMPT` 登记次数，改小了必须同步（stale 检测）

  `colorInfo` = `--info`、`fontFamily` = `--font-sans`、`FONT_LADDER` = `--fs-*`
- 共享原语规格由 `common/__tests__/listPrimitives.test.tsx` 锁定（分页预设、计数格式、RowActions 折叠 / 确认 / 危险色、StatusDot、CountLabel）
