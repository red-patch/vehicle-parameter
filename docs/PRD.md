# 产品需求文档 (PRD) - 智行参数管理系统

## 1. 项目概述

**项目名称**：智行参数管理系统 (Smart Vehicle Parameter Manager)
**版本**：V4.0
**日期**：2026-02-26
**状态**：已开发完成 (Implemented)

### 1.1 背景

在车辆工程或投标场景中，经常需要处理大量的车辆配置参数表。面临的痛点包括：

- **版本迭代频繁**：难以快速定位两个 Excel 版本之间的参数差异（新增、移除、数值变更）。
- **投标填报繁琐**：招标方提供的参数表格式各异，参数命名不统一（如“车身长度”vs“整车长”），人工查找并填报耗时且易错。

### 1.2 目标

开发一个基于 Web 的轻量级工具，实现：

1.  **自动化差异比对**：秒级识别 Excel 版本差异。
2.  **智能化参数填报**：利用模糊匹配算法自动完成招标文件参数填充，减少人工操作。

---

## 2. 核心功能详述

### 2.1 Excel 版本差异比对 (Version Diff)

**用户价值**：快速验证参数变更，确保数据准确性。
**功能逻辑**：

1.  **文件上传**：支持上传“基准版本”和“新版本”两个 Excel 文件 (.xlsx/.xls)。
2.  **数据解析**：自动识别表头（分组、参数名、参数值），生成标准化数据结构。
3.  **比对算法**：
    - **新增 (Added)**：新版本有而基准版本没有的字段。
    - **移除 (Removed)**：基准版本有而新版本没有的字段。
    - **变更 (Modified)**：字段存在但数值不一致。
    - **未变 (Unchanged)**：完全一致。
4.  **可视化展示**：
    - 统计概览（4 类状态的数量统计）。
    - 差异详情列表（支持分页、高亮显示变更前后的值）。

### 2.2 智能投标填报 (Smart Bidding Filler)

**用户价值**：大幅缩短投标文件制作时间，降低错填风险。
**功能逻辑**：

1.  **参数库建立**：复用“基准版本”作为标准参数库（Library）。
2.  **需求文件上传**：上传招标方的需求 Excel 表格。
3.  **智能匹配 (Fuzzy Matching)**：
    - 使用 **Fuse.js** 算法。
    - 计算“需求参数名”与“库参数名”的相似度。
    - 自动填充置信度最高的参数值。
4.  **人工审核与修正**：
    - 提供可视化审核界面。
    - **置信度提示**：高(绿色)、中(黄色)、低(红色)区分匹配质量。
    - **手动修正**：用户可通过下拉与搜索手动选择正确的参数进行纠正。
5.  **结果导出**：一键导出包含填报值的 Excel 文件。

### 2.3 快捷检索 (Quick Search)

- **全局搜索**：在预览参数表时，支持按“参数名”、“分组”或“数值”进行关键词过滤。

## 3. 技术架构 (Technical Architecture)

### 3.1 技术栈

- **前端框架**：React 19, TypeScript
- **构建工具**：Vite
- **UI 组件库**：Ant Design v6
- **样式库**：TailwindCSS
- **状态管理**：Zustand
- **核心算法库**：
  - `xlsx` (SheetJS)：Excel 解析与生成。
  - `fuse.js`：模糊字符串匹配。
  - `lodash`：数据处理工具。

### 3.2 数据流设计

- **Store (Zustand)**：
  - `baseFile` / `targetFile`：存储解析后的原始 Excel 数据。
  - `diffResult`：存储比对计算结果。
  - `requirementFile`：存储招标需求数据。
  - `matchResults`：存储由算法生成并经用户修正的匹配对列表。

---

## 4. 界面交互设计 (UI/UX)

- **主导航**：
  - [版本比对]：默认首页，左右分栏上传，底部展示比对结果。
  - [智能检索与填充]：上传需求表 -> 自动匹配 -> 审核列表 -> 导出按钮。
- **视觉风格**：
  - 简洁商务风（蓝/白/灰主色调）。
  - 使用 Tag 和 Badge 清晰标识状态。
  - 差异比对中使用 删除线(旧值) 和 绿色高亮(新值) 强化对比。
