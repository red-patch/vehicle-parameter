# 主文件退役：每车最新版（自动）+ 关键车型（人工）

"主文件"（每组一个、可人工指定、suggestPrimary 按 已审核→参数最全→最新 自动建议）被废除。原因：一个车型组内通常有**多辆不同的车**（不同公告号、不同电量/等级）——"每组选一个代表"会在数据层暗中替用户做业务选择（参数最全≈高级别车≈"主推"），而主推哪款是销售观点，数据永不自动判断；"参数最全的不一定最新"也使内容完整度失去权威资格。

替代的双层模型：**每车最新版**（同一身份键下 updatedAt 最新的活跃版本，程序自动判定，承担 ⚡ 激活/对比默认入口）+ **关键车型**（自由标签，人工打标，承担"主推/值得对比"语义）。同车多份活跃版本 = 版本链未收敛，治理体检提示一键收敛（旧的标 superseded）。

**Consequences**: 存量 isPrimary 标记一次性转换为「关键车型」标签；`suggestPrimary`/`buildAdoptPrimaryMeta`/缺主文件·多主文件报告删除；数据级别（公告/准入级 vs 开发/配置级）概念一并从界面撤除（它只是 Excel 模板差异的痕迹，其派生字段 审批状态/准入编号/准入等级 独立保留）。
**Considered Options**: 保留主文件但建议规则改为最新优先——被否：粒度错误（组≠车）不因排序规则而修复；主文件粒度改为每车——被否：与"每车最新版"重叠，多一个人工权威位徒增维护。
