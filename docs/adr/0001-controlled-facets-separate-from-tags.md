# 受控属性与标签分离（组级/资产级两层）

资产的客观事实维度（主机厂、车型族群、公告号、电池品牌、电量、准入等级）不再用自由标签承载，而是升格为独立的**受控属性（Facet）**层，取值受词表约束、支持别名归一；标签只保留自由观点（如"关键车型""客运版"）与系统来源标签。受控属性分两层：**组级**（主机厂、车型族群——一组一值、组内继承）与**资产级**（公告号、电池品牌、电量、准入等级——组内可多值、可缺失，"无"是合法状态）。车型族群是组级属性而非树层级：一个车型组唯一归属一个族群，"主机厂 → 车型组"是浏览主干，其余维度一律横切（维度内 OR、维度间 AND），支撑"跨主机厂比同类族群"的对比场景。

**Considered Options**: 全部继续用标签承载（现状）——被否：厂商标签已出现 40 种法人名写法无归一、准入等级标签覆盖率仅 75/255 且词表缺值，拼写漂移和口径打架是结构性的，不是打标纪律能解决的；树形逐层下钻（主机厂→族群→车型组）——被否：跨厂比同类需要逐厂走六遍，横切维度塞进树会把两个方向的查询变成一个方向。
