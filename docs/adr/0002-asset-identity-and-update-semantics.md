# 资产身份键与更新语义（永不静默覆盖、软删除默认）

资产的"同一辆车"由**身份键**判定：有公告号时为公告号（一公告号一车），无公告号的自建数据为车型组 + 产品名；文件名不做身份（文件名与车型名解耦、永不改文件名），参数内容哈希不做身份（内容变化是版本演进）。导入命中已有资产时默认**并存为新版本、旧版本自动标记 superseded**，交互式导入弹参数 diff 让用户三选（替换/并存/放弃）；**任何路径都不静默覆盖**——参数是人工校对过的资产，覆盖不可逆。删除默认是软删除（deprecated，可恢复），物理清理必须显式触发。"确定重复"（身份键命中）可程序判；"疑似重复"（公告号同而产品名不同等）只进人工裁定清单，永不自动合并。

**Consequences**: 存量数据中已存在的同公告号重复簇（并查集检出）按此语义一次性人工裁决后归并为版本序列；导入预览必须做三分类（新增/更新已有/疑似重复）。补充裁定（2026-10-01）：公告号相同但准入编号（ZR）或准入等级不同的，判定为**不同车型**而非疑似重复——准入编号都换新（重报）即新的准入记录；准入编号相同而等级不同的视为同车数据修正，仍走重复判定。
**Considered Options**: 文件名为身份 + 静默覆盖——被否：文件名与车型名已解耦，且覆盖不可逆；内容哈希去重——被否：会把合法的参数更新误判为新资产。
